# Deploy InSync v3.0.0

1. Download and unzip the full package.
2. Delete the old files from the GitHub Pages repository.
3. Upload **the contents** of the `InSync-v3.0.0` folder to the repository root.
4. Wait for GitHub Pages deployment to complete.
5. Open the Pages URL directly in Safari and refresh once.
6. Remove the old InSync Home Screen shortcut.
7. Use Safari Share → **Add to Home Screen**.

Local browser data is separate from the GitHub source files. Replacing repository files should not erase the profile stored on the same phone/browser.
