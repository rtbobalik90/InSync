# InSync v4.0.0 Deployment

1. Download the complete package and open the `InSync-v4.0.0` folder.
2. Replace the files in the GitHub Pages repository with the contents of that folder.
3. Wait for GitHub Pages deployment to complete.
4. Open the public site in Safari and refresh once.
5. Fully close and reopen the installed Home Screen app.
6. If the old icon or interface remains, remove the Home Screen shortcut and add it again from Safari.

Existing profile data is stored locally and should migrate without being erased. Export a backup first when possible.
